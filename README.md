# ego-start · 启动台

极简的 Chrome 新标签页扩展。把常用搜索和 AI 控制台收纳在一屏，打开新标签即可直接输入。

零依赖，纯静态，单文件样式。

## 功能

**搜索入口**（五个独立搜索框，回车直达对应站点）

| 站点 | 说明 |
|---|---|
| 必应国内版 | cn.bing.com |
| Google | 国际版 |
| 必应国际版 | 强制 en-US |
| 小红书 | 搜笔记 / 攻略 |
| 哔哩哔哩 | 搜视频 / UP 主 |
| SeedHub | hubdog.cc 资源检索 |

**控制台入口**

- DeepSeek 开放平台
- Kimi Code
- GLM Coding Plan（bigmodel.cn）
- 豆包语音大模型（火山引擎）

**交互细节**

- 记住上次使用的搜索引擎，打开新标签自动聚焦，开箱即输入
- `/` 快速聚焦搜索框，`Esc` 退出输入
- 自动跟随系统浅色 / 深色主题
- 背景环境光 + 无外部字体 / 图片 / 脚本依赖

## 安装

1. 克隆或下载本仓库
2. 打开 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择本目录

新标签页即被接管。

## 文件结构

| 文件 | 说明 |
|---|---|
| `manifest.json` | 扩展清单（Manifest V3，`chrome_url_overrides.newtab`） |
| `newtab.html` | 界面 + 内联样式（CSS 变量驱动的明暗双主题） |
| `newtab.js` | 搜索分发、上次引擎记忆、键盘交互 |
